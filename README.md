# BOSM'26 assets

Static images for BOSM'26 campaign emails. Hosted here so mail clients
can load them over a public HTTPS URL.

| File | Size | Used in |
|---|---|---|
| `bosm26-app-mockup.jpg` | 1200x1042 | App launch email, product shot |

Served via jsDelivr:

```
https://cdn.jsdelivr.net/gh/vicky123456c/bosm26-assets@main/bosm26-app-mockup.jpg
```

Do not rename or delete files that a sent email references. Mail sits in
inboxes long after the send, and a dead URL renders as a broken image.
